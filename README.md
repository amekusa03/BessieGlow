# BessieGlow (ベッシー電飾スタジオ)

プラモデル「ベッシー」のための、ESP32-C6 (ESP-IDF) を用いたLED発光制御システムです。
GPIO 0, 1, 2, 3 の4チャンネル白色LEDを、ハードウェアPWM（LEDC）により高精細に調光・制御します。

---

## 🌟 主な特徴

1. **Wi-Fi SoftAP & キャプティブポータル対応**
   - パソコンやスマホで Wi-Fi `Bessie-Glow` に接続するだけで、ブラウザが自動的に起動（ログイン画面ポップアップ）。
   - 初心者でもURLを入力する手間なく、すぐに操作画面が開きます。
   - （手動アクセスの場合: `http://192.168.4.1`）

2. **多彩なプリセットパターン（15種類以上）**
   - 宇宙船・航空機・自動車・特殊エフェクト・基本のカテゴリ別。
   - 動力炉ブレス、バーニア噴射、索敵スキャナー、航行灯＆ストロボ、ハザード、セルモーター始動、溶接スパーク、接触不良ノイズ、ホタル同期、常時点灯、全消灯など。

3. **4CH 個別マニュアル調光**
   - 「どこを光らせるか決まっていない」段階でも安心！
   - CH0〜CH3 のスライダーで、1灯ずつ個別に明るさを0〜100%調整可能。配線チェックや部位ごとのバランス調整が手元で行えます。

4. **リアルタイム・モニタリングUI**
   - スマホ画面上に現在のLEDの明るさがリアルタイムにバー＆ランプ表示。

5. **設定の自動保存 (NVS)**
   - 気に入ったパターンや明るさ・スピードに変更すると、数秒後に自動で内蔵フラッシュメモリに記憶。
   - プラモの電源を入れ直しても、前回一番気に入った光り方で即座に点灯します。

6. **高い拡張性**
   - 今後「こういうパターンが欲しい」と思った際、C言語の関数を1つ書いてリストに登録するだけで、Web画面のボタンも自動的に増える設計になっています。

## 🔌 ハードウェア接続

| ESP32-C6 ピン | 接続先 | 備考 |
| :--- | :--- | :--- |
| **GPIO 0** | 白色LED CH0 (アノード側 + 抵抗) | LEDC PWM 5kHz |
| **GPIO 1** | 白色LED CH1 (アノード側 + 抵抗) | LEDC PWM 5kHz |
| **GPIO 2** | 白色LED CH2 (アノード側 + 抵抗) | LEDC PWM 5kHz |
| **GPIO 3** | 白色LED CH3 (アノード側 + 抵抗) | LEDC PWM 5kHz |
| **GND** | 各LEDのカソード側 | 共通グラウンド |

※白色LEDには適切な電流制限抵抗（例: 330Ω〜1kΩ）を直列に接続してください。

## 🚀 書き込み手順

ESP32-C6 をUSBでPCに接続し、以下のコマンドを実行します。

```bash
# ESP-IDF環境変数の有効化
. ~/esp/esp-idf/export.sh

# シリアルポート（例: /dev/ttyACM0 または /dev/ttyUSB0）を指定してフラッシュ＆モニター
idf.py -p /dev/ttyACM0 flash monitor
```

## 🎨 パターンの追加方法（ベッシーの感想を受けて増やす時）

`main/patterns.c` に新しいアニメーション関数を書き、末尾の `PATTERN_LIST` 配列に1行追加するだけでOKです！
Web UIへのボタン追加やAPI連携は自動的に行われます。
